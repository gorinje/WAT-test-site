Cookie policy

This demo site sets cookies and uses browser storage for the sole purpose of testing the Website Auditing Tool. Non-essential trackers are only set after you agree, per category. You can change or withdraw your consent at any time using the "Manage cookies" button. The consent cookie wat_consent is kept for 6 months.

In non-compliant mode, the page deliberately reproduces prohibited practices: trackers are set before any choice is made, rejection is ignored and withdrawal has no effect. This mode exists to check that the auditing tool detects these breaches.
